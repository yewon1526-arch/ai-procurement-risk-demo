애리조나 바이오센서 연구실 구매 이력 분석 화면 추가
==================================================

1. 기존 GitHub 저장소 (yewon1526-arch/ai-procurement-risk-demo)의 app.py와
   procurement_ml.py는 수정하지 않습니다.

2. 저장소의 최상위에 pages 폴더를 만들고,
   pages/1_연구실_구매_이력_분석.py 파일을 업로드합니다.
   GitHub 웹에서 Add file > Create new file을 누르고
   파일 이름을 pages/1_연구실_구매_이력_분석.py 로 지정한 뒤
   다운로드한 .py 파일 내용을 붙여넣는 방법도 가능합니다.

3. Commit changes를 누르면 연결된 Streamlit Cloud 앱이 업데이트됩니다.
   자동 반영이 늦으면 Manage app > Reboot app 을 이용합니다.

4. 웹앱 왼쪽 메뉴에서 '연구실 구매 이력 분석' 페이지를 선택하고
   UA_Biosensor_Lab_Purchasing_SIMULATED_Upload.csv 파일을 업로드합니다.

5. 분석 가능한 항목:
   - 165건 모의 구매 이력, 프로젝트별 지출, 납기 지연 현황
   - 공급업체별 실제 이력 값 기반 납기·품질 통계
   - 같은 품목 코드로 과거 발주한 공급업체 간 비교
   - Random Forest 학습용 분류 실험(시간순 train/test split)

중요한 제한:
- CSV의 구매 기록은 합성 모의 데이터이며 실제 연구실 구매 원본이 아닙니다.
- 모델 ROC-AUC가 높지 않을 수 있습니다. 실무 예측성능을 의미하지 않습니다.
- 과거 이력으로 대체 공급업체의 제품 사양 및 재고, 실시간 가격을
  자동 검증하거나 실제 공급업체를 발굴하는 기능은 아직 없습니다.
- 기존 자동차 부품 공급 리스크 페이지는 그대로 유지됩니다.
